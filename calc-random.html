Генератор случайных чисел

Этот рандомайзер позволяет получить одно или несколько случайных чисел в заданном диапазоне. Можно настроить количество чисел, тип (целые или с десятичной частью), запретить повторы и выбрать способ сортировки.

—
Укажите диапазон, количество чисел и нажмите «Сгенерировать».

Для чего может пригодиться генератор случайных чисел

Случайный выбор помогает в самых разных ситуациях: разыграть порядок выступлений, выбрать победителя конкурса, придумать число для пароля или генерации тестовых данных. Такой генератор удобен тем, что не требует установки приложений и работает прямо в браузере.

Используемые числа генерируются с помощью встроенной функции Math.random() браузера и предназначены для бытовых и учебных задач. Для криптографически стойких операций (например, генерации ключей безопасности) рекомендуется использовать специализированные инструменты.
